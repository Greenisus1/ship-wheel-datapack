# ShipWheel datapack

Adds a craftable **Ship Wheel** (8 sticks around dark oak planks) and two commands:
- `/function shipwheel:give`
- `/function shipwheel:place_decor` / `/function shipwheel:remove_decor` (decorative wheel at your feet)

**Limit:** a datapack cannot drive a structure. Driving needs the ShipWheel plugin (Paper) or a mod.
Pair with the ShipWheel resource pack for the wheel model. Java 26.3 (data format 121). MIT.
